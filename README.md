# Traffic Sign Recognition using CNN & TensorFlow

This project focuses on classifying traffic signs using the **German Traffic Sign Recognition Benchmark (GTSRB)** dataset. Built with Python, TensorFlow, and Keras, it uses a Convolutional Neural Network (CNN) to achieve high accuracy in multi-class image classification.

---

## 📌 Features

- **Dataset**: German Traffic Sign Recognition Benchmark (GTSRB)
- **Model Architecture**: Convolutional Neural Network (CNN)
- **Classes**: 43 different categories of traffic signs
- **Frameworks**: TensorFlow, Keras, OpenCV, NumPy, Matplotlib
